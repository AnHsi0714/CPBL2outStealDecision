# 兩出局一壘有人，該不該跑？中職教練的跑壘決策指南

2026 台灣棒球數據分析競賽（現場分析戰術組）參賽專案。研究在**第 1–8 局、兩出局、僅一壘有人**的情境下，發動盜壘的損益兩平成功率門檻是多少，以及這個門檻如何隨打者棒次、打者類型、局數與比分（勝率視角）改變。資料涵蓋中職 2023–2026 四季，並以同一套方法擴充到 MLB 與 KBO 做跨聯盟對照。

核心貢獻是**保留效應**：盜壘失敗造成第三出局時，該打者的打席會保留到下一局重新開始，等於用「打序整體延後一棒」換取當下的出局風險，傳統 RE24 分析忽略了這點。

## 線上報告

**[all-leagues-report.html（整合入口）](https://anhsi0714.github.io/CPBL2outStealDecision/)**：三聯盟單頁整合入口，右上角 cpbl／mlb／kbo 標籤切換聯盟，再用分類與年份頁籤切換所有報告（決策門檻、RE24 矩陣、勝率矩陣、WPA 版門檻）。

本機 clone 後也可直接用瀏覽器開 `reports/all-leagues-report.html`（需與同資料夾的其他報告放在一起）。

## 安裝

Python 3.11+，只需兩個外部相依：

```bash
git clone https://github.com/AnHsi0714/CPBL2outStealDecision.git
cd CPBL2outStealDecision
pip install requests scipy
```

測試：`python -m unittest discover -s tests`

clone 下來沒有原始資料與中間輸出（不進版控），成品報告已放在 `reports/`，直接開網頁即可。要重跑分析請見 [方法說明.md](./方法說明.md)「重現結果」。

## 資料使用注意事項

- 資料來自各聯盟的公開來源：CPBL 官網逐球紀錄、KBO 官網文字轉播、MLB Stats API（Gumbo）逐打席紀錄，皆為自行抓取，請留意各來源的使用條款並控制抓取頻率；原始資料與程式碼分開管理，不進版控。
- 盜壘沒有結構化欄位，是從文字紀錄解析出來的。中職與 MLB 已對帳官方 box score，KBO 沒有可對帳的官方盜壘統計，數字可信度較低，詳見 [分析發現.md](./分析發現.md)。
